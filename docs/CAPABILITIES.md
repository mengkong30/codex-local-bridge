# 能力范围

[返回首页](../README.md) · 插件包 / 服务 0.8.3 · Figma runtime v11

先调用 local_figma_capabilities。返回可用命令、统一属性白名单、文字范围字段、操作类型与编辑器信息。17 个 MCP 工具通过结构化命令执行；没有任意 JavaScript 执行接口。

| 领域 | 0.8.2 新接入 | 仍需了解的边界 |
| --- | --- | --- |
| 图层管理 | 创建、真实删除、复制、跨父级移动、排序、分组与解组 | 页面/文档/slide grid 根节点不进入通用删除；移除原 ID 的操作不能用桥接快照恢复 |
| 图形与矢量 | Line、Polygon、Star、Section、Slice、Vector、vectorPaths/vectorNetwork；四种布尔运算与 flatten | 节点类型和字段以当前 Figma 支持为准，布尔运算/flatten 会替换或移除原节点 |
| 属性 | 创建和更新共用字段定义，包含旋转、圆角、阴影、描边、变换、遮罩等 | 字段不是对所有节点通用；不支持的字段会报错，不会静默忽略 |
| 布局 | 换行、Grid 轨道/间距/位置/跨度、HUG/FILL、绝对定位、尺寸上下限、constraints | Grid 的合法组合由 Figma 检查；已有自动布局仍可能触发整体重新排版 |
| 文字 | 按 UTF-16 范围设置字体、字号、颜色、行高、字距、大小写、装饰、超链接、列表和样式 | 字体必须可用；不同编辑器的文字子层与 Design TextNode 分开处理 |
| 组件 | 实例属性修改、组件交换、解绑、覆盖重置；保留原有组件/变体创建 | 内部覆盖与解绑后的 ID 不能完整快照，相关操作要求 allowNonUndoable:true |
| 变量/样式/库 | 多模式增改删、按模式赋值/别名、显式节点模式；四类样式 CRUD；库资产按 key 导入 | 模式数量受 Figma 套餐限制，库需手动启用；删除/导入资源不能承诺恢复原 ID |
| 原型 | set-reactions 传递官方 Reaction 数组，支持导航、Overlay、悬停、条件与变量动作等官方数据 | 字段结构必须符合当前 Figma API；写入与回读测试不等同于实际播放所有原型 |
| 导出 | PNG、SVG、JPG、PDF；尺寸约束、边界、色彩配置与 SVG 参数 | 图像 scale 上限 4；按宽/高导出上限 16384；未接入视频/GIF 与 REST JSON 导出 |
| 编辑器 | Design；FigJam 便签/形状/连线/表格；Slides 创建/网格/跳过/转场；Dev Inspect 只读 CSS/资源等 | 多编辑器是明确的基础操作集；不包含全部编辑器接口、代码生成、团队管理或发布能力 |

完整命令结构和例子见 [EXPANDED-API.md](EXPANDED-API.md)。

## 执行与恢复

页面绑定检查写入目标，独占文件绑定用于变量、样式、导入和 Slides 网格操作。同一连接串行，不同文件独立；无跨文件事务。多文件都需要运行插件。

复杂操作先 dryRun。幂等结果只在原服务实例、保留期限和容量内有效；超时后先查操作结果，不盲目重放。受支持快照最多保留最新 20 条/48 MiB，在当前插件会话内有效，并有冲突检查。

真实删除、解组、布尔、flatten、实例内部操作、资源删除/导入及编辑器专用操作明确返回 undo.supported:false，要求 allowNonUndoable:true，不能进入原子批次。Figma 原生撤销可用于人工恢复；桥接不会声称能重建原 ID。

## 验证范围

自动验收使用合成数据、模拟 API、实际组装的插件 runtime、隔离 HTTP/MCP 和浏览器界面。它验证命令映射、作用域、数据传递、结果查询和恢复边界；不替代真实 Figma 多编辑器、字体、套餐和原型播放验收。见 [TESTING.md](TESTING.md)。

服务只监听回环地址，无身份鉴权。任务 ID 提供路由与冲突隔离；云端 AI 的设计数据处理由宿主决定。见 [安全](../SECURITY.md)、[隐私](../PRIVACY.md)。
