# 能力范围

[返回首页](../README.md) · 当前插件包 0.7.2 / 服务 0.7.0 / Figma runtime v10

这是当前实现的功能边界，不是全部 Figma Plugin API 的覆盖声明。16 个 MCP 工具通过结构化命令工作；通用 command 工具仍受命令和字段白名单限制。

| 领域 | 当前支持 | 主要限制 |
| --- | --- | --- |
| 读取 | 文档、页面、选区、节点树、字体、部分变量和样式 | 节点读取使用字段白名单，不能导出全部 Figma 状态 |
| 创建 | Frame、组件、矩形、椭圆、文字、SVG、实例；高层构建支持部分 Vector | 缺少通用分组/解组、布尔运算、Section 和完整原生图形类型接口 |
| 修改 | 通用命令支持位置、尺寸、名称、填充、描边、透明度、文字内容/字号/对齐等 | 创建与更新白名单不同；通用更新不支持 rotation、cornerRadius、effects 等字段 |
| 文字 | 整段内容、字号、行高、字距和对齐；部分样式绑定 | 没有完整的字符范围编辑、富文本、列表与超链接写入接口 |
| 布局 | 方向、间距、内边距、基础对齐及尺寸模式 | 未完整接入换行、Grid、子项尺寸、绝对定位和约束控制 |
| 组件 | 创建实例、组合变体、新增组件属性、描述与替换实例 | 未完整接入实例属性编辑、交换/解绑与覆盖重置；部分操作不可撤销 |
| 变量/样式 | 本地集合、变量值、部分字段绑定、文字/效果样式 | 未完整接入多模式管理、团队库导入、颜色/网格样式管理 |
| 原型 | 可读取节点 reactions | 暂无原型交互写入命令 |
| 导出 | PNG、SVG | 暂无 JPG、PDF 及完整导出参数接口 |
| 文件与编辑器 | 已有 Design 文件中的页面；多文件分别接入 | 不创建全新 Figma 文件，不支持 FigJam、Slides 和 Dev Mode 专用接口 |

高层构建提供面板、指标卡、折线图、环图、示意地图、组件、变量集合和自动布局。地图来自输入数据构造的可编辑示意图，不自动获取地理数据。

## 任务控制与恢复

- 每页最多一个绑定；独占文件绑定用于全局资源操作。同一文件命令串行，不同文件独立，无跨文件事务。
- 复杂写入可 dry-run。幂等键和操作查询受原服务实例、24 小时与容量限制；服务重启后的未知结果不能盲目重放。
- 撤销依赖当前 Figma 插件会话中的有限快照，具有冲突检查；不是完整版本历史。组件属性、变体元数据和图像存储等存在恢复限制。

## 视觉检查

布局检查结合直接几何检查和启发式判断，不等同于完整无障碍认证。截图审阅使用宿主提供的 AI 视觉能力；没有协商 sampling 的宿主由当前 AI 看图并继续调用工具，插件没有独立的后台视觉模型。

修复限制在已审阅的节点和允许的字段内，最多三轮；内容改写和无法确定的布局调整需要用户任务范围支持。详见 [VISUAL-REVIEW.md](../VISUAL-REVIEW.md)。

## 数据与验证

桥接服务只绑定回环地址，无身份鉴权，页面和任务 ID 用于路由与冲突隔离。本机程序仍可访问该服务；云端 AI 的数据处理由宿主控制。见 [安全](../SECURITY.md) 与 [隐私](../PRIVACY.md)。

自动检查使用合成数据、模拟 Figma API 和隔离服务；测试通过代表现有用例通过，不代表全部 Figma 功能已接入或全部宿主均兼容。见 [TESTING.md](TESTING.md)。
