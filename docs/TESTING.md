# 验证范围

运行 `npm run check` 与 `npm test`，使用 Node 内置断言和模拟，无 npm 第三方依赖。测试端口应空闲，端口已占用时测试失败，不终止其他进程。

- reliability：多文件目标必选、跨连接结果拒绝、超时锁定、迟到结果恢复、重复确认、字体去重/预检失败、构建回滚、回传重试。
- security：Host/Origin、JSON请求类型、请求体限制与允许的 Figma / null 来源。它只验证这些规则，不证明服务具有鉴权或抵御所有攻击。
- mcp：真实 stdio 握手、工具发现、模拟目标读取、导出、非法输入、未知方法，不启动或读取真实设计。

发布前可在获授权的 Figma 副本中人工烟测：启动本版服务并运行本版 manifest；确认文档、运行v6能力，创建一个包含文字的临时 FRAME；回读文本对齐，导出并检查实际尺寸；关闭插件。记下实际验证的客户端版本。没有做完的项应明确记录，不把模拟测试写成真实 Figma 全功能验证。

本仓库的公开测试不含真实设计文件，也不为可点击原型、变量所有字段、跨版本字体或平台审核提供认证。
